# &lt;my-desktop-dock&gt;

A web component that represents a desktop dock containing icon buttons for launching different applications.

## Attributes

No custom attributes are required or used for this component.

## Events

| Event Name      | Fired When                        |
| --------------- | --------------------------------- |
| `desktop-dock:open-app`    | An icon button is clicked.        |

## Example

```html
<my-desktop-dock></my-desktop-dock>
```
