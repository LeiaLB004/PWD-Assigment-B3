# &lt;my-desktop&gt;

A custom web component representing a desktop interface with various applications.

## Attributes

None

## Events

| Event Name      | Fired When                        |
| --------------- | --------------------------------- |
| `desktop:clicked-icon`    | Clicked an icon       |

## Example

```html
<my-desktop></my-desktop>

```
