# &lt;my-weather-app&gt;

A web component that represents a simple weather application. It allows users to enter a city name and fetch the current weather information for that city.

## Attributes

No custom attributes are required or used for this component.

## Events

No custom events are fired by this component.

## Styling with CSS

`Weather-container` styles the container of the weather component.
`Input[type="text"]` styles the text input for entering the city name.
`Button` styles the button used to fetch the weather data.
`Weather-info` styles the container that displays the weather information.


## Example

```html
<my-weather-app></my-weather-app>
```
